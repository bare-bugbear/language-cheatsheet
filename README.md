# language-cheatsheet

Learn multiple languages at the same time.

A side-by-side syntax reference: **one row = one language feature, one column = one programming language**. Use it to learn several languages at once, or to map a construct you already know onto an unfamiliar language.

**How to read**

- Rows are grouped by topic; bold rows are section headers.
- Code is inline; `<br>` separates lines inside a cell, `&nbsp;` keeps indentation.
- `—` means the language has no native equivalent (a library or idiom is noted where useful).
- `\|` inside code is an escaped pipe, e.g. Python `int \| None`.
- Baselines: Python 3.10+, Go 1.18+, Rust 2021, Swift 5.9+, Kotlin 2.x, Java 21, Dart 3, ArkTS (HarmonyOS 5 / API 12+), JavaScript ES2022, TypeScript 5.x, C++20, C# 12, Ruby 3.x, PHP 8.x, Lua 5.4, Objective-C (ARC / modern syntax).
- Language coverage follows the 2026 TIOBE / Stack Overflow / GitHub Octoverse top lists. The original 8 columns keep their original order; JavaScript, TypeScript, C++, C#, Ruby, PHP, Lua and Objective-C are appended, for **16 languages** in total.
- An interactive, filterable version lives in [index.html](index.html). Open it directly in a browser; regenerate it with `python3 build.py` after editing this table.

## Notes

- **ArkTS is not TypeScript.** It enforces static typing at compile time: `var`, `any`, `unknown`, destructuring, function expressions, index signatures, conditional / mapped types and untyped object literals are rejected. Use `let` / `const`, arrow functions, `as T` casts and explicitly typed interfaces. See the [TypeScript-to-ArkTS cookbook](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/typescript-to-arkts-migration-guide-V5).
- **Version-sensitive rows:** `match` (Python 3.10), pattern switch & records (Java 14-21), generics (Go 1.18), Records & patterns (Dart 3), `std::format` / ranges / concepts (C++20), `std::expected` (C++23), collection expressions (C# 12), named arguments & enums (PHP 8), null safety (Dart 2.12 / C# 8).
- **Not covered yet:** C, Scala, Zig, Julia, R, Shell, SQL, Elixir, Haskell. To add a language, append one cell to every row and a column to the header, keeping the row order unchanged, then run `python3 build.py`.
- **Lua / Objective-C notes:** Lua has one compound type (`table`), 1-based indexing, no classes (metatables) and coroutines instead of threads; Objective-C uses message syntax `[obj msg]`, `@` literals, ARC, protocols and GCD. Luau (Roblox) and Objective-C++ differ in places.
- **Contributing:** snippets are minimal illustrative forms, not complete programs. Prefer the idiomatic modern syntax of each language; mark non-native features with `—`.
